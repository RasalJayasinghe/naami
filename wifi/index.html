Setup

Install, in order

UniFi menu names shift a little between versions. Look for the closest match.

  1. Check coverage before you buy

    In the Starlink app, check coverage and obstructions at the exact Kahawa spot where the dish will go.

  2. Install the dish and Starlink router

    Mount with a clear sky view, run the cable, power up and let it update in the Starlink app.

  3. Turn on Bypass Mode

    Starlink app → Settings → Router → Bypass Mode. Starlink's own Wi-Fi switches off. Undoing it needs a factory reset.

  4. Connect the UniFi gateway

    Starlink router Ethernet port → Cloud Gateway Ultra WAN port. Gateway LAN → PoE switch → access points.

  5. Set up UniFi

    Set up the gateway in the UniFi app, adopt the switch and access points, update all firmware.

  6. Create two networks

    Staff on the default network. A new Guest network for guests, kept apart from staff devices, tills and printers.

  7. Create two Wi-Fi names

    NAAMI Staff: password protected. NAAMI Guest: no password, Hotspot login page on, client device isolation on.

  8. Brand the login page

    Hotspot / Portal settings: sign-in method Voucher. Upload the logo and background, paste the text and colours from the next section.

  9. Create code profiles and print a batch

    Hotspot → Vouchers: one batch per code type from the table above. Print and file them at the desk.

  10. Speed test at the busiest time

    Test in the evening when the house is full. Adjust the code speeds so the total fits the link. Put the measured Mbps on the website.

  11. Test as a guest

    Join NAAMI Guest on an iPhone and an Android phone. Try a valid code, a wrong code and an expired one.

Before you order

Checks

  • Plan terms

    Residential vs Business

    Starlink sells Business plans for commercial sites. Read the Residential terms on guest and commercial use before relying on it for a hostel, and get a Business quote at starlink.com/en-lk/business to compare.

  • Coverage

    Exact location

    Confirm coverage and a clear sky view at the dish spot in the Starlink app.

  • Floor plan

    How many access points

    Walls, floors and the café layout decide the count. A sketch with room positions is enough for an installer to quote.

  • Power

    Backup runtime

    Decide how long Wi-Fi must survive a power cut, then size the UPS. That number also goes on the website trust strip.

  • Backup link

    Second connection, later

    If cowork grows, add local fibre or 4G as a backup. The UniFi gateway can switch over automatically.

  • Website

    Publish the facts

    Once tested, add the measured Mbps, backup power and code policy to the Work and House rules pages.
